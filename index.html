Featured Backend Project

Event Booking System

High-concurrency backend for event reservation and e-ticketing. Features optimistic locking via @Version to prevent double-booking during traffic surges, seat-lock expiration scheduling, Redis caching, and real-time seat availability pushed over STOMP WebSockets. Securely protected with JWT auth, refresh token rotation, Role-Based Access Control (RBAC), and BCrypt encryption. Includes QR-code e-ticketing, coupons, waitlists, Swagger/OpenAPI docs, and automated JUnit/Mockito security regression testing.

Production Deployment

LinkPulse – URL Shortener Platform

Production Java/Spring Boot URL shortener platform deployed on Render with containerized Docker builds and an automated GitHub Actions CI/CD pipeline.
